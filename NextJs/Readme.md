# NextJs

- Old approach followed in PHP and Wordpress is forming components at the server side
- Modern approach changed the server side components into client side components, that is whenever the user request a webpage, the entire webpage is forming for his alone in his laptop.
- Now the fullstack approach is, we are neglecting the flaws from both previous approach and using both client and server side components in a efficient way.

### Client Side Rendering
- Slower Initial Page load, because entire web page is bundling at the loading time, and some apis are fetched after the components are mounted.
- Highly Interactive.
- SEO (Search Engine Optimization) can be problamatic

### Server side Rendering
- Faster initial rendering, because the components are formed at the server side, ui just showing it.
- Less Interactive.
- SEO is very feasible.
